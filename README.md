## 📖 Tentang Repositori Ini
Tujuan utama dari repo ini adalah:
- Memberikan materi dasar algoritma dan sintaks C++.
- Melatih logika pemrograman khusus untuk kebutuhan robotika.
- Menyediakan latihan soal dan *mini-project* yang harus diselesaikan oleh anggota TRT.

---

## ⚙️ Prasyarat & Instalasi
Sebelum mulai ngoding, pastikan kamu sudah menginstal *tools* berikut di laptop/komputer kamu:

1. **Text Editor / IDE:** Disarankan menggunakan [Visual Studio Code (VS Code)](https://code.visualstudio.com/) atau [Arduino IDE](https://www.arduino.cc/en/software) untuk *testing* ke *board*.
2. **C++ Compiler:** 
   - Windows: Install MinGW / MSYS2.
   - Mac: Install Xcode Command Line Tools.
   - Linux: `sudo apt install build-essential`.
3. **Git:** Untuk mendownload dan mengumpulkan tugas (Download di [git-scm.com](https://git-scm.com/)).
